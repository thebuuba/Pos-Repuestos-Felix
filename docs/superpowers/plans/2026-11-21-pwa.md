# PWA para Repuestos Félix

**Objetivo:** instalar el POS en Android/iPhone, usar una interfaz táctil y preparar el servidor para HTTPS público conservando PostgreSQL y los respaldos existentes.

**Decisiones:** mantener JavaScript nativo y las pruebas actuales, sin cambiar de framework. El service worker guarda únicamente los archivos estáticos de la interfaz. Nunca intercepta la API ni guarda ventas sin conexión. Las actualizaciones esperan al cierre de las instancias abiertas para no interrumpir operaciones.

## Trabajo y comprobaciones

- [x] Añadir pruebas de navegación táctil, instalación y aislamiento de la caché respecto a API y escrituras.
- [x] Crear estilos adaptables, etiquetas persistentes, menús nativos y tablas con desplazamiento contenido.
- [x] Añadir manifiesto, iconos locales, service worker y ayuda de instalación para Android/iPhone.
- [x] Preparar alojamiento HTTPS con origen explícito y acceso por contraseña; mantener localhost por defecto. No crear credenciales reales ni publicar servicios en esta tarea.
- [x] Verificar todos los flujos con PostgreSQL temporal, revisar cambios y documentar instalación, conexión y límites del modo sin conexión.

La publicación real queda pendiente de las credenciales y del alojamiento: el usuario indicó configurar los archivos `.env` más adelante.

## Comprobacion

Pruebas de API/PostgreSQL, DOM y service worker. Revision de codigo independiente sin hallazgos sustantivos. Chrome reconoce la instalacion; verificacion visual en escritorio y emulacion iPhone SE de 375 px.
